# Propostes de noves funcionalitats per a la plataforma

1. **Panell de benvinguda personalitzat**: mostrar una portada diferent segons si l'usuari és docent, alumne o administrador, amb enllaços ràpids a les accions més habituals.
2. **Sistema de notificacions in-app i per correu**: avisar de noves proves assignades, revisions pendents, resultats publicats o comentaris del professorat.
3. **Calendari integrat amb recordatoris**: permetre veure totes les proves programades i lliuraments en un calendari sincronitzable amb Google Calendar o iCal.
4. **Analytics avançada amb filtres**: oferir gràfiques interactives per matèria, grup, dificultat i evolució temporal, amb exportació a CSV o PDF.
5. **Mode d'accessibilitat ampliat**: opcions de contrast alt, lectura de text en veu alta, navegació només amb teclat i configuracions per a dislèxia.
6. **Biblioteca de recursos multimèdia**: espai per guardar vídeos, imatges i documents relacionats amb les proves, amb etiquetes i permisos compartits.
7. **Sistema de gamificació per a l'alumnat**: punts, insígnies i reptes setmanals per fomentar la participació i la millora contínua.
8. **Integració amb LMS externs**: connectors per importar grups i notes des de Moodle, Google Classroom o Microsoft Teams.
9. **Suport per a rúbriques de correcció**: permetre definir criteris ponderats, exemplars i comentaris que es puguin reutilitzar en diferents proves.
10. **Centre d'ajuda interactiu**: tutorials pas a pas, assistent virtual i cercador de preguntes freqüents amb vídeos curts.
